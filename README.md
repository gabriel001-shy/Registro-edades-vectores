# Registro de Edades con Vectores en Python

## Descripción del proyecto

Este proyecto consiste en un programa desarrollado en Python que permite registrar y administrar las edades de varias personas mediante una lista utilizada como vector.

El programa permite mostrar las edades registradas, agregar nuevas edades, consultar y modificar registros, calcular el promedio e identificar la edad mayor y la menor.

## Funciones principales

* Mostrar todas las edades registradas.
* Agregar una nueva edad.
* Consultar una edad mediante su posición.
* Modificar una edad existente.
* Calcular el promedio de las edades.
* Identificar la edad mayor y la menor.
* Contar las personas registradas.

## Tecnologías utilizadas

* Python 3.
* Listas como estructuras de datos.
* Ciclos `for` y `while`.
* Condiciones `if`, `elif` y `else`.
* Funciones.

## Instrucciones para ejecutar el programa

1. Descargar el archivo `main.py`.
2. Tener Python 3 instalado en el equipo.
3. Abrir una terminal en la carpeta donde se encuentra el archivo.
4. Ejecutar el siguiente comando:

```bash
python main.py
```

En algunos equipos se puede utilizar:

```bash
python3 main.py
```
